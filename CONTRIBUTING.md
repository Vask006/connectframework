# Contributing to CONNECT Framework

Thank you for your interest in improving CONNECT Framework.

## Contribution Principles

- Keep changes aligned with the framework vision.
- Prioritize clarity, maintainability, and practical enterprise value.
- Avoid overbuilding early phases; evolve incrementally.

## Development Guidelines

- Week 1 focus is static web and documentation foundations.
- Propose architectural changes with rationale in pull request descriptions.
- Keep commits scoped and descriptive.

## Pull Request Checklist

- [ ] Change is aligned to roadmap and sprint scope
- [ ] Documentation updated (if behavior or intent changed)
- [ ] Website pages remain accessible and coherent
- [ ] No secrets or credentials included

## Reporting Issues

Please include:

- Problem statement
- Business/technical impact
- Steps to reproduce (if applicable)
- Suggested direction (optional)
