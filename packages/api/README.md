# CONNECT API (Phase 3 Scaffold)

Planned **.NET Web API** backend for governance operations.

## Planned endpoints (MVP)

- `GET /health` — service health
- `GET /tools` — tool registry listing
- `GET /governance/rules` — governance rules
- `POST /governance/evaluate` — evaluate asset against rules
- `GET /recommendations` — consolidation recommendations

## Target stack

- .NET 8 Web API
- PostgreSQL or Cosmos DB
- Semantic Kernel for AI-assisted analysis (Phase 5)

This folder is a placeholder until Phase 3 implementation begins.
