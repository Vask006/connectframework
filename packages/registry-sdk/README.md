# @connect-framework/registry-sdk (Phase 2)

TypeScript types and governance evaluation utilities for the CONNECT registry data model.

Implemented in `apps/web/src/lib/registry/` for the current monorepo. This package folder documents the intended extraction target for Phase 3.

## Exports (via web app)

- Canonical record types (Tool, API, Platform, GovernanceRule, Standard, Exception)
- `evaluateToolCompliance`, `evaluateApiCompliance`
- `getPortfolioComplianceSummary`
