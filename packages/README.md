# Packages

Shared libraries and service scaffolds for CONNECT Framework phases 3–6.

## Planned packages

| Package | Phase | Purpose |
| --- | --- | --- |
| `api` | Phase 3 | .NET Web API governance services |
| `governance-core` | Phase 3 | Rule evaluation primitives |
| `registry-sdk` | Phase 2 | Tool/API registry client contracts |
| `ai-assistant` | Phase 5 | RAG and explainability helpers |

Packages will be introduced incrementally as the MVP platform matures.
